TZ Bridge Settings

Where the boat's data comes from, and how the phone reaches this PC.

1Where the NMEA comes from

Add one input for each place data arrives. Use the same speed as the sending device: usually 4800 for GPS, compass and instruments, 38400 for AIS. "Auto" finds the speed by itself. If TimeZero is on this PC, give it a serial output on one end of a virtual COM pair (com0com) and pick the other end here, or use a TCP output.

2Links to TimeZero on this PC

A virtual COM pair is two COM ports joined like a cable: what goes into one comes out of the other. Use one pair to bring TimeZero's output to the bridge, and one for each device whose data the bridge passes on to TimeZero (an AIS receiver, say), so no splitter program is needed.
